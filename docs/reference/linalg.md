# Matrices and linear solvers

[Manual](../manual.md) · [API reference](index.md)

## E. Matrices

| name | kind | purpose |
|---|---|---|
| `Matrix` | class | a square banded matrix on one space or a `ProductSpace` |
| `RectMatrix` | class | a rectangular block between two spaces on one grid |
| `block(blocks, space=None, symmetric=None)` | function | assembles blocks into one banded `Matrix` on a `ProductSpace` |
| `MatrixInfo` | class | the measured structure of a `Matrix`, from `Matrix.classify()` |
| `ddot(x, y)` | function | the dot product of two coefficient vectors, in C++ without BLAS (E.5) |

### E.1 `Matrix`

Returned by `Form.assemble`, `Form.jacobian`, `V.mass_matrix`, `assemble` and
`block`. Not constructed directly. Stored as a band plus the corner entries of a
periodic space.

**Attributes**

| attribute | type | meaning |
|---|---|---|
| `shape` | tuple | `(n, n)`. |
| `symmetric` | bool, writable | The symmetry flag set by the assembler from the roles of the terms. `Auto` picks Cholesky when it is true. Set it yourself for a block-symmetric product form. |
| `periodic` | bool | Whether the matrix has periodic corner entries. |
| `space` | space, `ProductSpace` or `None` | The space the columns index, when known. |

**Solving and structure**

| method | inputs | returns | meaning |
|---|---|---|---|
| `solver(backend=Solver.Auto)` | `backend` a `Solver` member or a case-insensitive name: `"Auto"`, `"Dense"`, `"Band"`, `"SymBand"`, `"Cyclic"`, `"SymCyclic"`, `"Circulant"`, `"Diagonal"`, and the aliases `"fft"` (Circulant), `"banded"` (Band), `"symmetric"` (SymBand), `"diag"` (Diagonal). | `LinearSolver` | Factors the matrix once ([manual, Section 7](../manual.md#7-solving)). `Auto` chooses from the measured structure. `"fft"` refuses a matrix that is not circulant and names the cause. |
| `is_circulant(tol=1e-10)` | `tol` float, relative defect allowed | bool | Whether the matrix is generated by its first column. False for a non-periodic matrix. |
| `symbol()` | none | complex array, length `n` | The eigenvalues `fft(first column)` of a circulant matrix, in NumPy FFT wavenumber order. Raises `ValueError` when not circulant. Needs no FFTW. |
| `classify(tol=1e-12)` | `tol` float, the threshold for calling a defect zero | `MatrixInfo` | Measures bandwidth, symmetry, skew, circulant structure and diagonal dominance, and names the backend they call for ([E.4](#e4-matrixinfo)). |

**Products and conversion**

| method | inputs | returns | meaning |
|---|---|---|---|
| `A @ x` | `x` a vector (array or Function), or a 2D array of columns | `Function` of `A.space` when known, otherwise an array | Banded product, $O(n(2p+1))$. A complex `x` gives a complex array. |
| `A @ B` | `B` a `Matrix` | `Matrix` | Matrix product, half-bandwidth $p_A + p_B$, never flagged symmetric. |
| `A @ B` | `B` a `RectMatrix` whose row space is `A.space` | `RectMatrix` | Product with a block. |
| `matvec(x, out=None)` | `x` a vector or Function. `out` a C-contiguous `float64` array of length `n` that does not overlap `x`. | array | $Ax$ as a plain array. With `out` it is written there and nothing is allocated. |
| `inner(x, y=None)` | `x`, `y` vectors or Functions of length `n` | float | $y^{\mathsf T}Ax$, or $x^{\mathsf T}Ax$ without `y`, straight off the band without forming $Ax$ and without BLAS (E.5). An energy is `0.5 * M.inner(u)`. |
| `tocsr()`, `tocoo()` | none | SciPy sparse matrix | A copy in CSR or COO format. |
| `Matrix.from_scipy(S, periodic=False, space=None, symmetric=False)` | square SciPy sparse matrix | `Matrix` | The band holding the entries of `S` (entries farther than $n/2$ from the diagonal become periodic corners when `periodic=True`), ready for `.solver()`. |
| `copy()` | none | `Matrix` | An independent copy. Take one before updating in place a matrix returned by a constant form, since the form returns the same cached object each time. |
| `T` | attribute | `Matrix` | The transpose. For a skew matrix `A.T` equals `-A`. |

**Algebra**

| expression | inputs | returns | meaning |
|---|---|---|---|
| `A + B`, `A - B` | `B` a `Matrix` of the same shape and periodicity | `Matrix` | Half-bandwidth `max(p_A, p_B)`. Symmetric only when both are. `A + 0` is `A`, so `sum([...])` works. |
| `-A`, `a*A`, `A*a`, `A/a` | `a` a number | `Matrix` | Scaling. `A * B` between matrices is not defined, use `A @ B`. |
| `A += B`, `A -= B` | `B` a `Matrix` | `A` or a new `Matrix` | In place when `A`'s band is wide enough, a new matrix otherwise. |

**Accumulating terms**

| method | inputs | returns | meaning |
|---|---|---|---|
| `add(cache, a, b, coeff=1.0)` | `cache` a `QuadratureCache` of the space. `a` int, derivative on the test function. `b` int, derivative on the trial function. `coeff` a number or an array of values at the cache nodes. | `self` | Adds $\int c\,(D^a N_i)(D^b N_j)$. |
| `add_block(P, I, J, QI, QJ, a, b, coeff=1.0)` | `P` a `ProductSpace`. `I`, `J` int, row and column fields. `QI`, `QJ` caches of fields `I` and `J`. `a`, `b`, `coeff` as in `add`. | `self` | Adds the same term to block $(I, J)$. |

### E.2 `RectMatrix`

An operator from a trial space $V$ to a test space $W \ne V$ on the same grid,
$B_{ij} = a(S_j, T_i)$. It comes from a rank-2 form whose test and trial
symbols live in different spaces. Stored in FEMd's compressed sparse row store
(`_femd.CSRMatrix`, attribute `_K`) and never factored; the products, the transpose and
the algebra run in C++, and a square one serves `fd.gmres` and `newton_system` through the
C++ matvec and FEMd's sparse LU.

**Constructor** (rarely needed)

| argument | type | default | meaning |
|---|---|---|---|
| `A` | `_femd.CSRMatrix`, SciPy sparse matrix or dense array | required | The entries, shape `(row_space.dim, col_space.dim)`. A SciPy or dense input is copied into the CSR store, duplicates summed. |
| `row_space` | space | required | $W$, the test space. |
| `col_space` | space | required | $V$, the trial space. |

**Members**

| member | inputs | returns | meaning |
|---|---|---|---|
| `shape` | attribute | tuple | `(W.dim, V.dim)`. |
| `nnz` | attribute | int | Stored entries. |
| `row_space`, `col_space` | attribute | space | $W$ and $V$. |
| `space` | attribute | space | `row_space`, where `B @ x` lives. |
| `B @ x` | `x` an array of length `V.dim` or a Function of $V$, or a 2-D array with `V.dim` rows | `Function` of $W$, or an array | The product (column by column for a 2-D array). |
| `B @ A`, `B @ C` | `A` a `Matrix` on $V$, `C` a `RectMatrix` with row space $V$ | `RectMatrix` | Products, spaces checked. |
| `B.T` | attribute | `RectMatrix` | The transpose, from $W$ to $V$. |
| `B + C`, `B - C`, `-B`, `a*B`, `B/a` | `C` a `RectMatrix` on the same two spaces, `a` a number | `RectMatrix` | Algebra (a sum on the union of the two patterns; `B/a` is `(1/a)*B`). |
| `matvec(x, out=None)` | `x` a vector or Function of $V$. `out` an array to write the result into. | array | $Bx$ as a plain array, in C++. |
| `tocsr()`, `tocoo()`, `toarray()` | none | SciPy or dense | Copies, for inspection and interoperability. |
| `copy()` | none | `RectMatrix` | An independent copy. |

`solver()` raises `TypeError`. Put the block into a square system with `block`.

### E.3 `block(blocks, space=None, symmetric=None)`

**Inputs**

| argument | type | default | meaning |
|---|---|---|---|
| `blocks` | square list of lists | required | Entry $(I, J)$ is a `Matrix` (diagonal, on one plain space), a `RectMatrix`, or `None` or `0` for a zero block. Field $I$ must be one space for row $I$ and for column $I$, and every field needs at least one nonzero block. |
| `space` | `ProductSpace` | `None` | A product space to reuse. Its `fields` must be exactly the spaces of the block rows, in order. `None` builds `ProductSpace(*fields)`. |
| `symmetric` | bool or `None` | `None` | `None` measures the symmetry of the result and sets the flag. `True` or `False` sets it without the $O(n w)$ measurement. |

**Output.** One banded `Matrix` on the product space, position-numbered.
Solving it gives a `ProductFunction`.

### E.4 `MatrixInfo`

Returned by `Matrix.classify(tol)`. Every number is measured from the entries.
`print(info)` gives a summary.

| attribute | type | meaning |
|---|---|---|
| `n`, `shape` | int, tuple | Size. |
| `nnz`, `density` | int, float | Nonzeros and their fraction of $n^2$. Here and in the bandwidths, entries below $10^{-14}$ `scale` count as zero. |
| `bandwidth` | int | Measured half-bandwidth without the periodic wrap. |
| `cyclic_bandwidth` | int | Measured half-bandwidth counting the wrap. |
| `reserved_uband` | int | The half-bandwidth the space reserves. |
| `corner_entries` | int | Nonzeros outside the reserved band, the periodic wrap. |
| `block_period` | int | Smallest $q$ dividing $n$ under whose shift the matrix is invariant. 1 means circulant, 0 none. |
| `scale` | float | $\max \lvert A_{ij} \rvert$, the reference for the defects. |
| `symmetry`, `skew`, `circulant` | float | Relative defects $\max \lvert A_{ij} - A_{ji} \rvert$, $\max \lvert A_{ij} + A_{ji} \rvert$ (both over `scale`) and the defect against the circulant of the first column. |
| `diagonal_dominance` | float | $\min_i \left(\lvert A_{ii} \rvert - \sum_{j \ne i} \lvert A_{ij} \rvert\right)$ over `scale`, positive when strictly dominant. |
| `periodic`, `symmetric_flag` | bool | The matrix's own flags. |
| `is_symmetric`, `is_skew`, `is_circulant` | bool | The defects compared with `tol`. |
| `kind` | str | A description such as `"symmetric cyclic banded"`. |
| `backend` | str | The backend the measurements call for. |
| `auto_backend` | str | The backend `Auto` picks: the measured structure with the `symmetric` flag. It differs from `backend` only when the flag disagrees with the measured symmetry, or for `Circulant`. |
| `warnings` | list of str | Disagreements worth acting on, such as a wrong symmetry flag or unused diagonals. |
| `tol` | float | The tolerance used. |

### E.5 `ddot(x, y)`

The dot product $\sum_i x_iy_i$ of two coefficient vectors, arrays or Functions of one space, computed in C++.

NumPy's `x @ y` goes to the BLAS, and the OpenBLAS that some NumPy builds ship (Anaconda's on Apple silicon, for one) threads a dot product of more than 10 000 entries across every core. The hand-off can cost hundreds of microseconds for a few microseconds of work, and the threads keep spinning afterwards and slow everything else down. A time loop whose energies, dissipation rates and relaxation parameters are such dot products can spend most of its time there: the Navier-Stokes notebook of the Hamiltonian project took 96 s on an M4 instead of 20 s. `fd.ddot` does the sum in chunks of 4096 entries, each with eight interleaved partial sums held in vector registers, the chunk sums added in order, so it costs a few microseconds and gives the same bits for any number of threads. With OpenMP it is threaded from $2^{20}$ entries on.

| argument | type | meaning |
|---|---|---|
| `x`, `y` | arrays or Functions of the same length, real | The two vectors. Complex vectors raise `TypeError`; use NumPy for them. |

**Output.** A float. `Matrix.inner`, `RectMatrix` through `fd.ddot(y, B @ x)`, and `SparseMatrix.inner` ([L.3](elements-2d.md#l3-sparsematrix)) give $y^{\mathsf T}Ax$ in one pass over the matrix.

## F. Linear solvers

| name | kind | purpose |
|---|---|---|
| `LinearSolver` | class | a factored operator, from `Matrix.solver()` |
| `Solver` | enum | the direct solver backends |
| `solve(a, L, ...)` | function | assemble, lift boundary data and solve in one call |
| `gmres`, `lgmres` | function | preconditioned Krylov solvers |
| `KrylovInfo` | class | the convergence report of `gmres` and `lgmres` |
| `eigs`, `EigenResult` | function, class | sparse eigenproblems $Ax = \lambda Mx$ by shift-invert (F.7) |

### F.1 `LinearSolver`

Returned by `Matrix.solver(backend)`.

| member | inputs | returns | meaning |
|---|---|---|---|
| `solve(b, into=None, lift=None)` | `b` right-hand side, an array or Function of length `size`. `into` a Function to write the result into. `lift` a Function of `V.unconstrained` (usually `V.lift(...)`) or an array of `raw_dim` raw coefficients. | `Function` of the operator's space, `ProductFunction` on a product space, `into` when given, an array when the space is unknown | Solves $A c = b$. With `lift` it returns `V.prolongate(c) + lift` as a Function of `V.unconstrained`. A complex `b` gives a complex array and excludes `into` and `lift`. |
| `backend` | attribute | `Solver` | The backend chosen. |
| `pivoted` | attribute | bool | `True` when `Auto` fell back to the banded LU with partial pivoting: the matrix is not positive definite (the Cholesky refused it), or the pivot-free banded LU met a zero pivot. `backend` is then `Band`, or `Cyclic` for a matrix with periodic corners (the folded periodic LU below). |
| `size` | attribute | int | $n$. |
| `space` | attribute | space or `None` | The space results live in. |

### F.2 `Solver`

Members `Auto`, `Dense`, `Band`, `SymBand`, `Cyclic`, `SymCyclic`, `Circulant`,
`Diagonal`. What each requires and costs is in the table of [manual, Section 7](../manual.md#7-solving).
`Auto` measures the matrix, ignoring entries below $10^{-14}$ of the largest. It
picks `Diagonal` for a diagonal matrix, `SymCyclic` or `Cyclic` when there are
entries across the periodic seam, and `SymBand` or `Band` otherwise, the
symmetric ones when the `symmetric` flag is set. The banded backends factor the
measured band. It never picks `Circulant`. It factors at once and falls back to the banded LU with partial pivoting when the Cholesky meets a pivot that is not positive or the pivot-free LU breaks down (`LinearSolver.pivoted`). With periodic corners `SymCyclic` and `Cyclic` are checked on one solve (normwise backward error at most $10^{-11}$), and a matrix the Cholesky refuses or that fails the check is solved by partial pivoting on the band folded into the order $0, n-1, 1, n-2, \dots$, of half-bandwidth at most $2p$ (`pivoted` true, `backend` `Cyclic`). An explicit `SymBand` or `SymCyclic` raises `ValueError` on a matrix that is not positive definite.

### F.3 `solve(a, L, left=None, right=None, backend=Solver.Auto)`

Solves $a(u, v) = L(v)$ for all $v \in V$, with data on the built-in
conditions ([manual, Section 4](../manual.md#4-boundary-conditions)).

**Inputs**

| argument | type | default | meaning |
|---|---|---|---|
| `a` | rank-2 `Form` or its expression | required | The bilinear form. |
| `L` | rank-1 `Form` or its expression | required | The linear form, on the same test space. Natural data enter here through `ds`. |
| `left`, `right` | number, tuple or `None` | `None` | Values of the functionals built in at each end, as in `V.lift`. Needs a square form on one plain space. Without them, the data given with the space are used, if any. |
| `backend` | `Solver` or name | `Solver.Auto` | Passed to `Matrix.solver`. |

**Output.** A `Function` of `V.unconstrained` when data are given, of `V`
otherwise, or a `ProductFunction` on a product space.

### F.4 `gmres(A, b, M=None, x0=None, *, restart=30, maxiter=None, tol=1e-10, warn=True)`

Left-preconditioned GMRES(`restart`) ([manual, Section 7.1](../manual.md#71-krylov-solvers)).

**Inputs**

| argument | type | default | meaning |
|---|---|---|---|
| `A` | `Matrix`, square `RectMatrix`, object with `.matvec`, or callable $x \mapsto Ax$ | required | The operator. With a `Matrix` the product runs in C++. |
| `b` | array or Function | required | Right-hand side. Real only. |
| `M` | `None`, `LinearSolver`, `Matrix`, object with `.solve`, or callable $r \mapsto M^{-1}r$ | `None` | Left preconditioner. A `Matrix` is factored once with `Auto`. A `LinearSolver` runs in C++. |
| `x0` | array or Function | `None` | Initial guess, zero when `None`. |
| `restart` | int | `30` | Krylov subspace size before a restart. Capped at $n$. |
| `maxiter` | int or `None` | `None` | Iteration limit, `max(1000, 10*restart)` when `None`. |
| `tol` | float | `1e-10` | Bound on $\lVert M^{-1} r \rVert / \lVert M^{-1} b \rVert$. |
| `warn` | bool | `True` | Issue a `RuntimeWarning` when `tol` is not met. |

**Outputs**

| output | type | meaning |
|---|---|---|
| `x` | `Function`, `ProductFunction` or array | The solution, a Function when `A` knows its space. |
| `info` | `KrylovInfo` | The convergence report. |

### F.5 `lgmres(A, b, M=None, x0=None, *, restart=20, k_aug=2, maxiter=None, tol=1e-10, warn=True)`

LGMRES, GMRES that keeps `k_aug` error approximations across restarts, which
helps where GMRES($m$) stagnates. Inputs and outputs as `gmres`, with a
different `restart` default and one more argument.

| argument | type | default | meaning |
|---|---|---|---|
| `k_aug` | int | `2` | Number of augmentation vectors kept across restarts. |

### F.6 `KrylovInfo`

| attribute | type | meaning |
|---|---|---|
| `converged` | bool | Whether `tol` was met. |
| `iterations` | int | Iterations taken. |
| `residual` | float | The true relative residual $\lVert b - Ax \rVert / \lVert b \rVert$, recomputed at the end. |
| `precond_residual` | float | $\lVert M^{-1}(b - Ax) \rVert / \lVert M^{-1} b \rVert$, what `tol` bounds. |
| `method` | str | `"gmres"` or `"lgmres"`. |

### F.7 `eigs(a, m=None, k=6, sigma=0.0, symmetric=None, which="nearest", tol=0.0, maxiter=None, ncv=None, vectors=True, backend="auto", v0=None)`

The $k$ eigenpairs of $A x = \lambda M x$ nearest `sigma`, by shift-invert Arnoldi in C++
(`solve/eigen.hpp`, `_femd.arnoldi_largest`; Lanczos in the $M$ inner product when symmetric), with
$(A - \sigma M)^{-1}$ applied through FEMd's factorization of the shifted matrix (manual,
[Section 7.10](../manual.md#710-eigenproblems)).

| argument | type | default | meaning |
|---|---|---|---|
| `a`, `m` | form, expression, `Matrix` or `SparseMatrix` | required, `None` | $A$ and $M$ on one space. `m=None` is $M = I$ (2D `SparseMatrix` only). |
| `k` | int | `6` | Number of eigenpairs, $1 \le k < n - 1$. |
| `sigma` | float | `0.0` | The shift. It must not be an eigenvalue. |
| `symmetric` | bool or None | `None` | `None` measures $A$ and $M$. `True` needs $M$ positive definite. |
| `which` | str | `"nearest"` | `"largest"` iterates on $M^{-1}A$ without a shifted factorization, `"smallest"` is the shift $0$. |
| `tol`, `maxiter`, `ncv` | float, int, int | `0`, `None`, `None` | The relative residual tolerance of a Ritz pair ($10^{-10}$), the restarts (300), the Arnoldi vectors per restart ($\max(2k+1, 20)$). |
| `vectors` | bool | `True` | `False` skips the eigenvectors. |
| `backend` | str | `"auto"` | The solver of the shifted matrix. |
| `v0` | array or None | `None` | The starting vector. `None` is a fixed pseudo-random vector, so results are reproducible. |

**Returns** an `EigenResult`: `values` (sorted by distance to `sigma`, then by value), `vectors` (the
eigenvectors as columns), `functions` (one Function per eigenvector, when the matrix knows its
space), `residuals` (the backward error $\lVert Ax - \lambda Mx\rVert / ((\lVert A\rVert_1 + |\lambda|
\lVert M\rVert_1)\lVert x\rVert)$ of each pair), `symmetric`, `sigma`. `lam, X = fd.eigs(...)` unpacks it.

**Raises** `ValueError` for a `k` out of range, an unknown `which`, or a shifted matrix that cannot be
factored or an iteration that does not converge within `maxiter` restarts, and `TypeError` for an
argument that is not a form or a matrix.
